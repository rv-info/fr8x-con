# Platform Roadmap

## Phase 1: Core Reverse-Auction Engine (Completed)
* Auction creation, container specification tables, mandatory rate heads.
* Real-time bidding ranks (Client read-only).
* Basic authentication, role-based controls.

## Phase 2: Collaboration Feed & Rate Center (Completed)
* Post composer, rate spreadsheets with bulk download templates.
* Currency ticker at 28px height.

## Phase 3: Identity & Professional Networking (Completed)
* Crop/resize picture uploading for users and company logos.
* Permanent handle routing (`/profile/@handle`, `/company/@handle`).
* GSTN, PAN, CIN registration fields in company profile settings.
* Universal search dashboard with filters, autocomplete, and history logs.
* Network partner connections model, mutual connections, industry matches.
* Awards reactions, comments, up/down voting, and multi-tier verification.
* Sponsored ad blocks in feeds and sidebars.

## Phase 4: Future Enhancements (Roadmap)
* **Real-time Chat**: Direct messaging between network partners.
* **Payment Gateway Integration**: Auto-billing for monthly Basic subscriptions and Job postings fee (UPI / Cards).
* **Automatic Cargo Matching**: Smart AI alerts matching RFQ requirements to specialized carrier tags.
* **Mobile Apps**: Dedicated React Native or PWA wrappers for mobile views.
