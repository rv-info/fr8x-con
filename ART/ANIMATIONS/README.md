# ART ANIMATIONS REPOSITORY

This directory is designated for all animation assets used in FR8X Connect.

## Guidelines & Supported Formats
1. **Preferred Format**: Animated WebP (.webp) or SVG-based SMIL/CSS for modern performance.
2. **Legacy Looping Animations**: GIF (.gif) supported for simple UI loaders, status pulses, and lightweight looping indicators.
3. **Transparent Alpha Channel**: Must maintain transparency to blend smoothly with both light (#F8FAFC) and dark backgrounds.
4. **Size Limitation**: Looping animations must be strictly under 1MB to preserve bandwidth.
5. **Naming Convention**:
   - `animation_loading.gif` / `animation_loading.webp`
   - `animation_radar_pulse.webp`
   - `animation_success_check.webp`
