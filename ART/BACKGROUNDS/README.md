# ART BACKGROUNDS REPOSITORY

This directory is designated for structural background textures, SVG patterns, and header backdrops in FR8X Connect.

## Guidelines & Supported Formats
1. **Preferred Formats**: SVG for vector geometric grids and subtle dot patterns; WebP for photographic backdrops.
2. **Use Cases**:
   - Trade lane global map watermark patterns
   - Freight passport subtle Guilloche security background patterns
   - Landing page hero gradients
3. **Naming Convention**:
   - `bg_grid_pattern.svg`
   - `bg_world_map_light.svg`
   - `bg_passport_watermark.svg`
