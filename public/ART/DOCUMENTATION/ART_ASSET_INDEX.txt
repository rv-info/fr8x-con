1. ARCHITECTURAL OVERVIEW & NAMING CONVENTION
--------------------------------------------------------------------------------
The ART directory serves as the centralized, immutable root repository for all
visual assets utilized across FR8X Connect. To eliminate scattered, duplicated,
and ambiguous graphic files, all visual assets are classified into standardized
functional domains:

  /ART
    /ICONS            - Interface, navigation, transport mode & action symbols
    /LOGOS            - Corporate identity, brand marks & email headers
    /PROFILE          - User avatars, company badges & identity graphics
    /ILLUSTRATIONS    - Empty-state graphics, banners & contextual artwork
    /ANIMATIONS       - Looping UI animations, status spinners & telemetry motion
    /3D               - Intermodal containers & maritime vessel GLB/GLTF models
    /BACKGROUNDS      - Security patterns, Guilloche passport watermarks & grids
    /DOCUMENTATION    - Master inventory index, schemas & replacement guidelines

NAMING CONVENTION STANDARD:
All filenames MUST follow explicit lowercase semantic naming:
  <domain>_<descriptor>.<ext>
Examples:
  - navigation_dashboard.png / navigation_dashboard.svg
  - navigation_rates.png / navigation_rates.svg
  - transport_ship.png / transport_ship.svg
  - action_calculator.png / action_calculator.svg
  - status_verified.png / status_verified.svg
  - logo_primary.png / logo_primary.svg
  - profile_default.png
  - illustration_empty_rates.png
  - animation_loading.gif

FORBIDDEN FILENAMES:
Never upload files named image1, icon2, newlogo, final, finalfinal, or temp.

2. ASSET REPLACEMENT & HOT-SWAP CONVENTION
--------------------------------------------------------------------------------
To replace any existing icon, logo, or illustration without modifying application
source code:
  1. Identify the target filename from this index (e.g., ART/LOGOS/logo_primary.png).
  2. Overwrite the file in ART/<CATEGORY>/ with the new file using the EXACT same
     filename and dimensions.
  3. The application references these assets via the centralized Asset Registry
     (/lib/assets/registry.ts) and /ART/ route handler. Replacing the file
     automatically cascades the update across the entire application.
  4. Ensure PNG graphics preserve 32-bit RGBA transparency (alpha channel).
